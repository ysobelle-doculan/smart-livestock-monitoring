# Farm Link

IoT-based livestock health monitoring system using wearable sensors, Azure cloud services, machine learning, and a Flutter mobile app.

## Overview

This repository contains the full codebase and documentation for the Farm Link capstone project. The system is designed to support livestock monitoring through sensor data collection, cloud-based processing, health prediction, and mobile visualization.

## Repository Structure

- `docs/` – Project documentation, setup guides, architecture notes, diagrams, and reports.
- `firmware/` – ESP32 and sensor-node code for wearable data collection.
- `gateway/` – LoRa/LoRaWAN gateway configuration, packet decoding, and edge-processing logic.
- `cloud/` – Azure Functions, backend services, database integration, and cloud workflows.
- `ml/` – Datasets, preprocessing, training, inference, and model evaluation files.
- `mobile-app/` – Flutter mobile application for dashboards, alerts, and animal monitoring.
- `shared/` – Shared schemas, constants, payload samples, and reusable utilities.
- `infra/` – Deployment scripts, environment templates, and infrastructure configuration.
- `tests/` – Integration tests, pipeline tests, and validation assets.
- `archive/` – Deprecated code, older prototypes, and legacy experiments.

## Goals

- Support real-time livestock health monitoring.
- Integrate cloud-based telemetry ingestion and processing.
- Apply machine learning for health-state prediction.
- Provide a user-friendly farmer-facing mobile application.
- Preserve project continuity for future capstone teams.
